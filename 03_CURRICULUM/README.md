# Curriculum

This area contains W.I.S.D.O.M. instructional architecture and course material.

Curriculum material is developmental unless explicitly promoted to canon.

A central design problem is the bridge between:

1. understanding what AI is doing well enough to work with it intelligently;
2. deciding what the learner wants to accomplish;
3. establishing the practical environment needed to begin;
4. developing disciplined habits before unnecessary complexity is introduced.
