# Theory / Practice Boundary

W.I.S.D.O.M. intentionally separates theory from practice without isolating them.

## Theory asks

- What is the system doing?
- Why does this method work?
- What failure modes should the learner expect?
- What principles should govern decisions?

## Practice asks

- What does the learner do next?
- Which account, tool, repository, file, or interface is required?
- What sequence produces a useful result?
- How is the result checked?

Instruction should provide an intelligible bridge between these layers.
