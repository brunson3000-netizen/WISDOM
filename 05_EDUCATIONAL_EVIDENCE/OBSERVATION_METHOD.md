# W.I.S.D.O.M. Learner Observation Method

## Purpose

W.I.S.D.O.M. is being designed while an actual learner is independently learning modern AI-assisted engineering.

This creates an opportunity to preserve real learning events rather than reconstructing an idealized learning path afterward.

The learner record is evidence for course architecture and research.

It is not itself curriculum and is not assumed to represent all learners.

## Evidence model

W.I.S.D.O.M. should distinguish four evidence sources:

1. longitudinal observation of an actual learner;
2. evidence from real AI-assisted engineering projects;
3. external educational, technical, and market research;
4. later testing with additional learners.

No single source is sufficient by itself.

## What to observe

Useful learning events include:

- a concept that was unexpectedly difficult;
- a concept that became easy after another concept was understood;
- missing prerequisite knowledge;
- terminology friction;
- tool or interface friction;
- mistakes caused by misunderstanding AI behavior;
- mistakes caused by project or workflow structure;
- successful mental models;
- failed mental models;
- moments when theory became practically useful;
- moments when practice exposed missing theory;
- repeated questions or repeated reasoning;
- unnecessary complexity;
- points where deterministic tooling replaced repeated manual reasoning;
- transfers of understanding from one project or problem to another.

## Event record

When useful, an observation should preserve:

- approximate date;
- learner objective;
- prior understanding;
- obstacle or uncertainty;
- action taken;
- role played by AI;
- outcome;
- conceptual lesson candidate;
- whether the lesson has repeated;
- competing explanation or counterexample;
- confidence.

Not every interaction deserves a record.

## Anti-overfit rule

A lesson derived from one learner is initially a hypothesis.

Promotion toward general course architecture should seek corroboration through:

- repetition across substantially different tasks;
- independent project evidence;
- external research;
- later learner observation or testing.

## Retrospective versus prospective evidence

Events reconstructed from memory or old conversations must be marked retrospective.

Events captured while or shortly after they occur are prospective observations and generally provide stronger evidence about the actual learning process.

## Privacy and relevance

Preserve only information useful to instructional research.

Personal facts unrelated to learning should not be collected merely because they are available.
