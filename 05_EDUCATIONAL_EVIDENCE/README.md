# Educational Evidence

This area preserves evidence from real AI-assisted work that may inform W.I.S.D.O.M. instruction.

Candidate sources include project histories such as S.W.A.R.M. and G.A.M.E.

Evidence should preserve:

- source project;
- relevant date or phase;
- problem encountered;
- attempted approach;
- result;
- failure or correction where applicable;
- educational inference;
- confidence or limitations.

A project event is evidence of what happened.

It is not automatically proof of a general educational principle.
