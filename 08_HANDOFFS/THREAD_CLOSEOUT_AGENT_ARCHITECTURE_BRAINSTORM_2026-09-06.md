## Provisional material preserved

The strongest surviving classroom architecture candidate is:

**Primary Coordinator alone → Coordinator + one worker → Coordinator + two workers**

The staged sequence is intended to let a learner observe the architectural differences rather than encounter a multi-agent system as unexplained ceremony.

Related surviving candidates:

- repository/project foundation precedes the experiment;
- the learner receives a lightweight constitutional posture before substantial agent work;
- deeper constitutional principles can be reinforced just in time when practical events make them relevant;
- comparable tasks are necessary to isolate architecture effects;
- added agents must be allowed to demonstrate negative value as well as positive value.

These remain noncanonical.
