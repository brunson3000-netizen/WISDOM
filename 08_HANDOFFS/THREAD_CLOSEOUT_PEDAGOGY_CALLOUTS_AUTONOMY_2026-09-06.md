## Probational

### Minimal callout framework

Current families:

1. Connection;
2. Field Check;
3. Principle in Action.

Convergence and causal-chain/evidence tracing are currently modes of Connection rather than independent families.

This is intentionally the narrower interpretation of the latest brainstorming because the project explicitly prefers fewer foundational callout families. A fourth family should be added only if real use exposes a function that cannot be represented cleanly by these three.

### Learner-autonomy primacy

Curriculum serves the learner; learner dignity and autonomy outrank fidelity to an instructional mechanism.

Standards of truth, evidence, and demonstrated competence remain intact.
