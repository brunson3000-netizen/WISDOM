# Windows execution profile (host COMMAND-POST)

Operational facts for agent sessions on this Windows host. Each actor verifies them once per session and records what it used in its status record. This file grants no authority and changes no project rule; a project's own instructions govern where they differ. Linux commands stay as the project writes them; only the Windows form differs.

Verified 2026-10-03 with Claude Code 2.1.288, codex-cli 0.160.0, Python 3.13.15 and Git 2.55.0.windows.3. Recheck after a tool upgrade.
